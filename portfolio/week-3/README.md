## Week 3 Focus

This week focuses on combining UrbanStyle data across the `sales`, `customers`, `products`, and `inventory` tables using SQL JOINs.

The main techniques are:

- INNER JOIN for matching records
- LEFT JOIN for keeping all records from one table
- LEFT JOIN + WHERE IS NULL for identifying missing relationships
- Multi-table JOINs for combining customer, sales, and product information
