# Week 0 — Onboarding

## Practice table
The `team_members` table contains fictional UrbanStyle.ltd team members together with my own practice row. It was created to verify that my Supabase database setup works.

## Query
The `hello_urbanstyle.sql` query returns the `id`, `name`, `role`, `week`, and `joined_at` fields from the `team_members` table, ordered by `id`.

## Check
I checked that the same practice records appear when I query the table through VS Code and SQLTools as when I view the data in Supabase.

## Limitation
This table contains only practice data, so it cannot tell me anything about UrbanStyle.ltd's real sales, customers, revenue, profitability, or business performance.
