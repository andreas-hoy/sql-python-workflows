## Relational Databases & Analytics Workflows

**Purpose:** 
This repository documents my structured upskilling in software engineering and backend practices. As an Applied Climatologist, my core expertise lies in translating atmospheric processes and multi-dimensional datasets (e.g., ERA5, IFS) into scientific assessments and tools (like AtmoPulse). 

While AtmoPulse currently runs locally via Python (xarray, Streamlit), I am using this 10-week curriculum to methodically learn the database and automation fundamentals required to eventually scale prototypes into robust, web-deployed operational services.

**Current Focus Areas:**
* **Relational Database Basics:** Learning PostgreSQL and SQL fundamentals to understand user-state management and data relationships.
* **Data Cleaning & Aggregation:** Writing SQL workflows for structured data analysis and anomaly detection.
* **Pipeline Automation:** Exploring version control (GitHub Actions) and API fetches as stepping stones toward future cloud deployment.
