# Relational Databases & Analytics Workflows for Climate Services

**Purpose:** 
This repository documents my structured upskilling in software engineering and backend practices. As an Applied Climatologist, my core expertise lies in translating atmospheric processes and multi-dimensional datasets (e.g., ERA5, IFS) into scientific assessments and tools (like AtmoPulse). 
While Atmopulse currently runs locally via Python (xarray, Streamlit), I am using this 10-week curriculum to learn the database architecture and automation skills required to scale this and future prototypes into robust, web-deployed operational services.


**Current Focus Areas:**
* **Relational Database Architecture:** Exploring PostgreSQL and SQL fundamentals to evaluate future user-state management and API integrations.
* **Data Cleaning & Aggregation:** Writing SQL workflows for structured data analysis.
* **Pipeline Automation Fundamentals:** Exploring GitHub Actions and API fetches as a stepping stone toward future Continuous Integration/Deployment (CI/CD) implementation.
